# LeadPredictor

A sales funnel calculator that turns a revenue target into the number of
**prospects**, **leads** and **customers** a campaign needs, and spreads that
work across the months of the campaign.

> Exam project for the SoftUni course *Programming Fundamentals with AI*.

## Status

Project scaffold. The application is being built feature by feature.

## Running locally

No build step and no dependencies — it is plain HTML, CSS and JavaScript.

```bash
# any static server works, for example:
npx serve .
```

Or simply open `index.html` in a browser.

## Deployment

Deployed to Netlify from the `main` branch. Configuration lives in
[`netlify.toml`](netlify.toml); `publish` is the repository root and there is no
build command.
